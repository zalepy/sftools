# sftools
tools for satisfactory

Current operation:
* scripts under `craw` were used to scrape data from 'https://satisfactory-calculator.com' and store it under the `data` directory. 
  You can re-run if data is outdated, but be sure to make a copy of the current data, as the scrape may be outdated too. 
* setup root demand in `calc_by_demand`
  ```
    root_demand_item = items['Smart Plating']
    root_demand = {'Smart Plating': Demand(name='Smart Plating', item=root_demand_item, rate=2.0, _type=DemandType.PRODUCE)}
  ```
    where `items` is loaded from the json stored in the `data` directory

Output:
Each step of the calculation generates lists of objects of two types:
- ProductionNode - describes production required to fulfil the need of specific item
- Demand - demand generated by the production node

 
Notes on calculation:
* buildings needed to satisfy the demand are shown as `float`
* number of buildings is rounded up before processing sub demands
* aggregation of production nodes, and pending demand is done after each step,
  however demand that occurs on separate layers/iterations will be rounded up
  individually


To start web server execute:
`waitress-serve --port=8000 "sftools_service.main:app"`

Plans are:
* once full graph of the "round-up" demand is available, show it in a web page (Done)
* allow tweaks via web interface to adjust _production nodes_ e.g. by using power shards to overclock a building
* allow representation of lines, and consideration of splitting limitations


## Web Interface

To run the web interface locally:

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the server:
   ```bash
   uvicorn main:app --reload
   ```
3. Open http://127.0.0.1:8000 in your browser.


## Deployment on Render

This application is ready for deployment on [Render](https://render.com/).

1. Create a new **Web Service**.
2. Connect your repository.
3. Use the following settings:
    - **Runtime**: Python 3
    - **Build Command**: `pip install -r requirements.txt`
    - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
